# DataServices

Target data-service templates. The reference implementation is **CustomerDataService** (API, Application, Domain, Contracts, Database, Migrations, Tests).

FindingsMigration scaffolds new domains from this shape. Keep SQL database projects and EF migrations projects non-overlapping.
